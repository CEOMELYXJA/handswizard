✦ HANDSWIZARD

Transforme ton iPhone en souris aérienne, ou contrôle Windows avec tes mains devant une webcam. Deux modes, un même objectif : ne plus avoir à tenir une souris classique.

📱 1 · iPhone dans les airs

Incline ton téléphone pour déplacer le vrai curseur Windows. Calibre les mouvements, clique et fais défiler. La page mobile est disponible uniquement sur l'adresse HTTPS privée de ton ordinateur, pas ici.

Installer Python, Tailscale et le programme Windows avant de connecter l'iPhone.

✋ 2 · Mains nues

Bouge ta main pour déplacer le curseur. Pince pouce-index pour cliquer ou glisser, pouce-majeur pour le clic droit; lève l’index et le majeur pour défiler. Le traitement est local sur le PC. Le programme Windows est nécessaire; cette version est expérimentale et doit être testée avec ta caméra.

🔒 Connexion privée

Ce site GitHub Pages explique le projet et permet d'en récupérer le code. Il ne contrôle aucun ordinateur et ne reçoit aucun mouvement. Pour l'iPhone, l'adresse de contrôle est fournie par ton propre PC via Tailscale Serve. N'active pas de tunnel public.
